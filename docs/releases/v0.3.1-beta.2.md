POSIRC 0.3.1-beta.2 expands the first beta's CPU and Unix coverage and includes
all commands, input and configuration improvements since 0.3.0-beta.1.

### Changes

- `/list`, `/me`, `/whois` and `/set` for the quit message, part message and real name.
- Up recalls the last submitted message or command; history keeps one entry.
- Long chat messages wrap in their conversation buffer. Server replies stay on
  one row, with `***` marking truncation, keeping channel lists readable.
- Conversation buffers omit repeated channel-name prefixes. Pipe output keeps
  its documented TSV format.
- Long input scrolls horizontally without corrupting the TUI, including UTF-8,
  combining marks and wide characters.
- A small editable `~/.posirc` file remembers server, TLS port and nickname.
  Explicit flags override saved settings; pipe modes do not access the file.
  Local nickname choices are limited to 15 Unicode characters.
- Portable pipe error handling checks the stream error as well as `fflush`.
  This detects closed downstream pipes even with libc implementations that
  return success from `fflush` after a failed buffered write.
- Every binary archive now includes POSIRC's GPL-3.0-only license.

### Downloads and validation

The full platform table and CPU/ABI distinctions are in the
[README](https://github.com/vash909/POSIRC/blob/v0.3.1-beta.2/README.md#beta-downloads)
and [portability notes](https://github.com/vash909/POSIRC/blob/v0.3.1-beta.2/docs/releases/PORTABILITY.md).
All published targets pass unit/configuration tests, real curses rendering
checks, local verified TLS 1.2/1.3 sessions and real CLI input/output pipe tests.
The same client functionality is enabled in every package.

Native runners validate Linux x86-64/ARM64 and macOS; other targets use CPU
compatibility mode, QEMU user emulation or full-system VMs. See BUILD-INFO.txt in
each archive for the exact source revision, compiler, libraries and execution.
Emulation does not certify every physical CPU, operating-system version or ABI.

Choose the matching OS/CPU/ABI archive, verify it with SHA256SUMS, extract it,
then run `./posirc --version`. The matching source archive is also included.
Static Linux packages embed their C library, OpenSSL and wide ncurses; glibc
packages require glibc 2.39+. Other Unix packages use the documented OS libraries.
macOS packages require 15+ and are ad-hoc signed, not notarized.

CA certificates, terminal descriptions and a UTF-8 locale remain external.
Use `-c /path/to/ca-bundle.pem` when your system's trust-store location differs.

```sh
./posirc -s irc.example.net -n yournick -j '#channel'
printf '%s\n' 'hello' | ./posirc -s irc.example.net -n yourbot -j '#channel'
./posirc -o -s irc.example.net -n logger -j '#channel' </dev/null | tee chat.tsv
```

### Beta limits

No SASL, server passwords, automatic reconnect, IRCv3 negotiation or automatic
flood pacing. The classic 512-byte IRC frame limit remains. A completed TLS write
is not proof of recipient delivery. Static-library security updates require a
new POSIRC binary. POSIRC is GPL-3.0-only; dependencies retain their own licenses.
