First public POSIRC beta: a small C99 IRC client with verified TLS, a Unicode
terminal UI, separate conversation buffers and Unix pipe input/output.

### Downloads

| Platform | CPU / archive suffix | Validation |
| --- | --- | --- |
| Linux | `x86_64-musl` | Native x86-64 |
| Linux | `x86-musl` | 32-bit x86 compatibility mode |
| Linux | `aarch64-musl` | Native ARM64 |
| Linux | `armv7-musl` | QEMU, ARMv7 hard-float |
| Linux | `armhf-musl` | QEMU, ARMv6 hard-float |
| Linux | `riscv64-musl` | QEMU, RISC-V 64-bit |
| Linux | `ppc64le-musl` | QEMU, PowerPC 64-bit little-endian |
| Linux | `s390x-musl` | QEMU, IBM Z 64-bit big-endian |
| macOS 15+ | `macos15-arm64` | Native Apple Silicon |
| macOS 15+ | `macos15-x86_64` | Native Intel |

Linux executables statically link musl, ncurses and OpenSSL, avoiding a dependency
on the host's glibc or shared OpenSSL version. macOS executables embed ncurses
and OpenSSL and use Apple's system libraries. macOS downloads are ad-hoc signed,
not notarized. Every archive includes build metadata, dependency versions,
installation instructions and third-party license notices. All targets execute
unit, curses, local TLS and real CLI pipe tests before publication.

Download the matching archive, extract it and run `./posirc --version`.
Verify downloads with `sha256sum -c SHA256SUMS` (or `shasum -a 256` on macOS).
A CA trust store and terminal descriptions remain necessary. Use
`-c /path/to/ca-bundle.pem` if your CA location differs from the compiled defaults.
Choose an available nickname and quote channel names:

```sh
./posirc -s irc.example.net -n yournick -j '#channel'
printf '%s\n' 'hello' | ./posirc -s irc.example.net -n yourbot -j '#channel'
./posirc -o -s irc.example.net -n logger -j '#channel' </dev/null | tee chat.tsv
```

### Included in this beta

- Verified TLS, channel/query buffers, user lists, Unicode editing and IRC colors.
- Bounded memory and queues; stdin streaming and flushed TSV output.
- Correct outgoing status: `[queued]` disappears after a complete TLS write;
  retained messages discarded before that point show `[unsent]`.
- ASCII processing and history-allocation optimizations, with published
  before/after measurements and low-level memory/I/O documentation.

### Beta limits

No SASL, server passwords, automatic reconnect, persistent configuration,
IRCv3 negotiation or automatic flood pacing. Messages use the classic IRC
512-byte frame limit. A completed TLS write is not proof of recipient delivery.
QEMU tests validate execution but do not certify every physical CPU or kernel.
Static-library security updates require an updated POSIRC binary.

Other POSIX systems can build from the included source archive; Windows-native,
BSD, MIPS, SPARC and LoongArch binaries are not part of this release. The CI
publishes the release only when every listed target passes; no untested
cross-compiled executables are included.
